# Рыба Бар — сайт ресторанов (Симферополь)

Статический сайт без сборки: откройте `index.html` (для шрифтов лучше через любой веб-сервер, например `python3 -m http.server`).

| Что поменять | Где |
|---|---|
| Телефоны, часы, адреса, Instagram, Telegram | `assets/config.js` |
| Меню и цены (отдельно для каждого заведения) | `assets/menu.js` (`g` — Горького, 6А; `sc` — Сергеева-Ценского, 6) |
| Блок третьего проекта семьи (МОА Рест) | `sister` в `assets/config.js` |
| Фото | `assets/photos/` (`имя.jpg` + уменьшенная `имя-sm.jpg`), подписи галереи — массив `PH` в `assets/script.js` |
| Политика конфиденциальности (реквизиты оператора) | `privacy.html` |

Анимации (`assets/sea.js`): живой аквариум на первом экране (рыбки в стиле гравюр из меню, пузырьки, лучи; рыбки пугаются курсора и плывут к корму по клику), бумажные рыбки на нитках как на веранде, чайки, неоновые звезда и ракушка, иллюминаторы, спасательный круг «наверх», табличка «ЗАНЯТО» после брони. Всё рисуется кодом, без видеофайлов; при настройке «уменьшить движение» анимации отключаются. Видео на первый экран можно включить параметром `heroVideo` в `assets/config.js`.

Разделы: заведения, меню с поиском и фильтрами, акции, события, галерея с просмотром фото, онлайн-заявка на бронь (WhatsApp / звонок / копирование), отзывы и карты Яндекса, FAQ.
